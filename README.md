# Self Assessment


Completing the Computer Science program and developing my ePortfolio has allowed me to reflect on how much I have grown as a programmer, problem solver, and future software developer. Throughout the program, I have developed technical knowledge while also improving the professional skills needed to succeed in the technology field. The projects I completed challenged me to apply programming concepts, design software solutions, manage databases, and think critically about improving existing applications. Creating this ePortfolio allowed me to demonstrate not only the final products I created but also the thought process, problem solving skills, and continuous improvements that went into developing them.
I also gained experience considering the needs of different stakeholders by designing software that focused on usability, reliability, and maintainability. Creating applications from the user's perspective helped me understand that successful software development requires more than writing code; it also requires understanding the needs of the people who will use the application.
One of the most valuable areas of growth was strengthening my understanding of data structures and algorithms. Throughout my coursework, I learned how selecting appropriate data structures and organizing information efficiently can improve software performance and readability. During my capstone enhancements, I improved my Event Tracking App by replacing a generic data structure with a dedicated Event data class and implementing alphabetical sorting. These improvements increased code readability, maintainability, and organization while preserving the application's functionality. This experience reinforced the importance of designing software that is both efficient and easy to maintain.
The Computer Science program also strengthened my understanding of software engineering principles. I learned the importance of planning software before development, organizing code into reusable components, writing maintainable code, and continuously improving existing applications. Rather than simply creating new programs, I learned how to evaluate an existing application, identify weaknesses, and implement meaningful enhancements that improve the overall quality of the software. These software engineering practices became a major focus throughout my capstone project.
Another important area of growth was database design and management. Through multiple courses and my capstone enhancements, I gained experience working with SQLite databases to store, retrieve, update, and delete application data. For my database enhancement, I improved the Event Tracking App by preventing duplicate event records and optimizing database queries to retrieve event information in alphabetical order. These improvements demonstrated my understanding of database integrity, efficient SQL queries, and the importance of organizing data effectively within an application.
Security has also been an important topic throughout the Computer Science program. I learned that security should be considered throughout every stage of software development rather than added at the end of a project. My coursework introduced concepts such as user authentication, input validation, secure database queries, and protecting sensitive information.
Developing my ePortfolio has also helped shape my professional goals. When I first entered the Computer Science program, my primary goal was to become a software developer. As I progressed through the curriculum, I developed a broader understanding of software engineering, databases, algorithms, mobile application development, and emerging technologies such as artificial intelligence. These experiences strengthened my desire to pursue a career in software development while continuing to expand my technical knowledge and adapt to new technologies throughout my career.
The artifacts included in this ePortfolio work together to demonstrate the range of skills I developed during the Computer Science program. Each enhancement highlights a different area of computer science while building upon the same Event Tracking App.
Overall, this ePortfolio represents my growth throughout the Computer Science program and demonstrates both my technical abilities and my commitment to continuous learning. The knowledge and experience I gained through my coursework have prepared me to enter the computer science profession with confidence. I look forward to continuing to develop my skills, learning new technologies, and contributing to software solutions that solve real-world problems.
